# 开发规范

## 1. UI 线程约束

- 所有用户可见行为和任务都不得阻塞 UI。
- 耗时操作必须放到后台异步执行。
- UI 刷新应在任务完成后回到 UI 线程处理。

## 2. 异步规范

- 所有异步接口统一返回 `Task` 或 `Task<T>`。
- 不允许使用 `async void`，除非是框架强制要求的事件入口且已做最小封装。
- 事件处理优先转发到可测试的 `Task` 方法。

## 3. 存储规范

- 本地读写不能占用 UI 线程。
- 读写失败要可恢复，避免阻塞主界面。
- 写入优先使用临时文件再替换正式文件。

## 4. 语言与扩展

- 中文和英文为内置语言。
- 其他语言通过用户放置语言包扩展。
- 文案必须通过资源或语言包读取，不硬编码在界面里。
- XAML 间距优先使用 `Margin` 控制，不使用空 `Grid` 行/列充当分隔。
