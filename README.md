### 工作日规则

**按周算**: 每n周为一个周期循环 以当前周为第1周
- 假如你是大小周 本周是小周 那么你可以设置成 第一周五天 第二周六天
- 假如你是大小周 本周是大周 那么你可以设置成 第一周六天 第二周五天
- 假如你是逆天的大中小周(61 52 43这样) 本周是中周 那么你可以设置成 第一周五天 第二周四天 第三周六天

**按天算**: 上x休y 今天是轮转的第z天
